% The keys:
%   bar        the bar down the left edge and the section headings
%   band       the band behind section headings
%   accent     bullet dashes
%   muted      subtitles, places and dates, the address
%   rule       the rule above the contact footer, chart ticks
%   highlight  a contrasting color for an honor under a term (honor = true)
%   pending    \fillin{...} placeholders
%   gradeAp gradeA gradeB gradeC   squares for A+, A/A-, B+/B/B-, C and below;
%              also the term bars
%   gradeRem   squares for credits still to come
%   pieceAp pieceA pieceB pieceC   the tint inside a course outline
%   strokeBC   the outline of B and C courses (A courses use their square color)
%   chartText  small chart text
